# LM Arena для Ollama

Оболочка в стиле LM Arena для слепого сравнения двух локальных моделей Ollama. Один промпт отправляется обеим моделям; ответы показываются без указания модели; пользователь выбирает лучший. Результаты накапливаются в JSON; по кнопке «Показать итоги» данные уходят в архив и создаётся новая серия.

**Репозиторий:** [https://github.com/andreyko75/LMarena4ollama](https://github.com/andreyko75/LMarena4ollama)

## 🎯 Описание

В рамках задания по локальному развёртыванию LLM реализована веб-оболочка для сравнения двух моделей Ollama (по умолчанию **llama3.2:3b** и **gemma2:2b**):

* Один и тот же промпт отправляется обеим моделям через Ollama API.
* Ответы отображаются как «Ответ 1» и «Ответ 2» без раскрытия модели; порядок случайный.
* Пользователь голосует кнопкой «Эта лучше»; под каждым ответом показывается время генерации.
* Все раунды сохраняются в JSON (промпты, ответы, время, голоса). По кнопке «Показать итоги» текущий файл переносится в архив, создаётся новый пустой — можно начать серию заново.

---

## 🚀 Функционал

* Слепое A/B-сравнение двух моделей Ollama в браузере.
* Параллельная генерация ответов и замер времени по каждой модели.
* Сохранение раундов в JSON с полной структурой (промпт, answer1/answer2, time1/time2, model1/model2, vote).
* Архивация данных при нажатии «Показать итоги» и кнопка «Начать заново» для новой серии.
* Сообщение после голоса: какая модель получила предпочтение; приглашение ввести следующий промпт.

## ⚙️ Установка и настройка

### Требования

* Python 3.9+
* [Ollama](https://ollama.com) — установлен и запущен локально

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/andreyko75/LMarena4ollama.git
cd LMarena4ollama
```

### Шаг 2: Виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate   # macOS/Linux
# .venv\Scripts\activate   # Windows
```

### Шаг 3: Зависимости

```bash
pip install -r requirements.txt
```

### Шаг 4: Модели Ollama

Загрузите две модели (по умолчанию в приложении используются llama3.2:3b и gemma2:2b):

```bash
ollama pull llama3.2:3b
ollama pull gemma2:2b
ollama list
```

Чтобы сравнивать другие модели, измените константы `MODEL_A` и `MODEL_B` в `server.py`.

**Важно:** убедитесь, что Ollama запущен (`ollama serve` или приложение Ollama) перед стартом сервера.

## 💻 Использование

### Запуск сервера

```bash
python server.py
```

В консоли появится адрес: http://localhost:3000

### Работа в браузере

1. Откройте http://localhost:3000
2. Введите промпт и нажмите **Сравнить** — появятся два ответа с временем генерации.
3. Выберите лучший ответ кнопкой **Эта лучше** под одним из блоков; появится сообщение, какой модели отдан голос.
4. Повторите с новыми промптами при необходимости.
5. Нажмите **Показать итоги** — страница очистится, отобразятся счёт по моделям; текущие данные уйдут в архив, создастся новый пустой JSON.
6. Нажмите **Начать заново**, чтобы вернуться к форме и начать новую серию сравнений.
